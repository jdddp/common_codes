这个属性面板怎么用？
属性就是「名称 + 值」：属性库存的是可复用的属性名，值在每次上传/导入时按需填写，值一律按文本存（可以从"已有的值"里直接挑，也可以填新的）。勾选即关联、取消勾选即移除（不用按 Ctrl、也不用再点"添加"），留空的属性不会提交。库里没有的先点「新建属性…」建立（建好即入库，下次直接复用）；每次上传都是同一批属性时点「复用上次」，属性和值一起带出来、预填值标橙色提醒确认。文件归属、类别这类信息同样只是一个普通属性，需要时自己在属性库建一个即可。
内置属性、不可删除。默认是今天，可改成实际作业日期； 按时间范围筛数据就靠它；留空则本次不带日期
属性条件 可叠加多个属性条件（条件之间是“并且”），全部来自属性库；筛选只有「等于」一种，值是文本；输入框里可直接从“已有的取值”里挑（也可以手输新值）
预览文件名目录大小 协议帧数状态上传时间操作
属性库管理 属性库存的是可复用的属性名（值一律按文本存，不设类型）；已被文件用过的属性不允许删除（要删就先清掉文件上的该属性值）
属性名已用创建时间操作
